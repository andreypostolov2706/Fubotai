2.1. FuBotai — это Telegram-бот для генерации изображений и видео с использованием искусственного интеллекта.

2.2. Сервис предоставляет доступ к следующим функциям:
- генерация изображений из текстовых описаний;
- редактирование изображений;
- генерация видео из текстовых описаний;
- анимация изображений.

2.3. Для использования Сервиса требуется внутренняя валюта (GTON), которую можно приобрести через встроенную систему оплаты.
