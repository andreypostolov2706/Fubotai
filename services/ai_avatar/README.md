# 🎭 AI Avatar Service

Сервис для создания говорящих видео с синхронизацией губ на основе Creatify Aurora (fal.ai).

## 📋 Описание

AI Avatar превращает статичное фото в реалистичное говорящее видео:
- Загружаете фото персонажа
- Добавляете аудио или текст для озвучки
- Получаете видео с синхронизацией губ, эмоциями и жестами

## ✨ Возможности

- **Реалистичная синхронизация губ** - естественные движения рта
- **Эмоции и жесты** - живые выражения лица и движения тела
- **Качество до 720p HD** - профессиональное качество видео
- **Поддержка любых языков** - работает с любым аудио
- **Голосовые сообщения** - можно записать голосовое прямо в боте
- **TTS интеграция** (в разработке) - озвучка текста

## 🎬 Как использовать

### Создание видео

1. Нажмите "🎬 Создать видео"
2. Загрузите фото персонажа (JPG, PNG, WEBP)
3. Выберите режим:
   - 🎤 Загрузить аудио (MP3, WAV, M4A)
   - 📝 Ввести текст для озвучки (TTS)
4. Подтвердите генерацию
5. Дождитесь результата (~30-45 сек)

### Настройки

- **Качество видео**: 480p (стандарт) или 720p (HD)
- **TTS**: Включение/выключение автоматической озвучки текста

### История

- Просмотр всех созданных видео
- Повторная загрузка видео
- Повтор генерации с теми же параметрами

## 💰 Стоимость

Цена рассчитывается за секунду видео:

| Качество | Цена fal.ai | Наша цена (+30%) | За 10 сек |
|----------|-------------|------------------|-----------|
| 480p     | $0.10/сек   | ~0.013 GTON/сек  | ~0.13 GTON |
| 720p     | $0.14/сек   | ~0.018 GTON/сек  | ~0.18 GTON |

**Примеры:**
- 5 секунд (480p): ~0.065 GTON
- 10 секунд (720p): ~0.18 GTON
- 15 секунд (480p): ~0.195 GTON

## 🔧 Технические детали

### API

- **Провайдер**: fal.ai
- **Модель**: Creatify Aurora
- **Endpoint**: `fal-ai/creatify/aurora`

### Лимиты

- Максимальная длительность видео: 60 секунд
- Максимальный размер файла: 10 МБ
- Поддерживаемые форматы изображений: JPG, PNG, WEBP
- Поддерживаемые форматы аудио: MP3, WAV, M4A, OGG, AAC

### База данных

Таблица `ai_avatar_generations`:
- История всех генераций
- Параметры запроса
- Результаты и метрики
- Стоимость в USD и GTON

## 📦 Установка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка API ключа

1. Получите API ключ на [fal.ai](https://fal.ai)
2. В админ-панели бота: Сервисы → AI Avatar → Настройки
3. Введите API ключ в поле `fal_api_key`

### 3. Регистрация сервиса

```bash
python services/ai_avatar/install_service.py
```

### 4. Перезапуск бота

```bash
supervisorctl restart fubotai
```

## ⚙️ Конфигурация

### Настройки сервиса (админ)

```python
{
    "fal_api_key": "",                    # API ключ fal.ai
    "margin_multiplier": 0.3,             # Маржа +30%
    "prices": {
        "480p": 0.10,                     # Цена за секунду 480p
        "720p": 0.14,                     # Цена за секунду 720p
    },
    "referral_bonus_enabled": True,       # Реферальные бонусы
    "referral_bonus_percent": 10,         # 10% бонус
    "gallery_channel_id": "",             # ID канала для галереи
    "gallery_enabled": False,             # Публикация в галерею
    "max_video_duration": 60,             # Макс. длительность (сек)
    "max_file_size_mb": 10,               # Макс. размер файла (МБ)
}
```

### Настройки пользователя

```python
{
    "quality": "480p",                    # Качество по умолчанию
    "use_tts": False,                     # Использовать TTS
}
```

## 🐛 Решение проблем

### Видео не генерируется

1. Проверьте API ключ в настройках
2. Убедитесь, что фото содержит четкое лицо
3. Проверьте формат и размер файлов
4. Посмотрите логи: `tail -f logs/fubotai.log`

### Ошибка "Content policy"

Изображение или аудио не прошли модерацию fal.ai. Используйте другой контент.

### Файл не пришёл

1. Проверьте интернет-соединение
2. Видео может быть слишком большим для Telegram
3. Скачайте по прямой ссылке из истории
